# Trilhas de Aprendizagem por Nivel

## Trilha para nivel iniciante
Colaboradores iniciantes devem comecar pelos fundamentos: Logica de Programacao com Java e SQL Essencial. Nao e recomendado iniciar por mensageria, microsservicos ou temas avancados antes de dominar a base.

## Trilha para nivel intermediario
Colaboradores intermediarios devem consolidar a construcao de sistemas: APIs REST com Spring Boot, Docker na Pratica e Introducao a Machine Learning com Python. Sao cursos praticos, com projeto ao final.

## Trilha para nivel avancado
Colaboradores avancados devem focar em arquitetura e integracao: Arquitetura de Microsservicos e Mensageria com RabbitMQ. Tambem e esperado que atuem como mentores dos niveis iniciante e intermediario.

## Colaborador ainda nao classificado
Quando o nivel ainda nao foi classificado pelo modelo de Machine Learning, a recomendacao deve seguir a trilha de nivel iniciante ate que a classificacao seja feita.
