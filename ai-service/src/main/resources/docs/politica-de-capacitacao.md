# Politica de Capacitacao Corporativa

## Objetivo da politica
Todo colaborador deve concluir pelo menos dois cursos por semestre. Os cursos sao escolhidos de acordo com o nivel de competencia classificado pela plataforma e com os interesses informados pelo colaborador.

## Carga horaria
O colaborador pode usar ate 4 horas semanais do expediente para estudo. Cursos tecnicos longos devem ser feitos um por vez para nao prejudicar as entregas do time.

## Prioridade por area
Colaboradores da area de Tecnologia devem priorizar cursos de programacao, APIs, Docker e arquitetura. Colaboradores da area de Dados devem priorizar SQL e Machine Learning com Python. Lideres e Tech Leads devem incluir pelo menos um curso comportamental, como Comunicacao e Lideranca.

## Protecao de dados
Agentes de IA e sistemas de recomendacao nao podem usar e-mail, documentos pessoais ou salario do colaborador. Apenas cargo, area, nivel e interesses podem ser usados para orientar a trilha.
